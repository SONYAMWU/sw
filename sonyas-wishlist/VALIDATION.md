# Проверка проекта — 11 ноября 2026

Проверено в этой среде:

- `npm install`: установка завершилась; npm audit сообщил 0 уязвимостей на момент установки.
- `npm run build`: TypeScript и production-сборка Vite завершились успешно.
- `npm test`: миграция выполнена в PGlite (PostgreSQL); прошли проверки RLS для гостя, администратора и обычного Auth-пользователя, изоляции токенов, недоступности SQL RPC извне, повторной брони, неверных/старых токенов, отката транзакции при конфликте, лимита запросов и однократной модерации.
- Проверен синтаксис TypeScript серверной функции и JavaScript интеграционного теста.
- В браузере проверены главная страница без настроенной базы, фильтры как элементы интерфейса, переход в административную страницу, мобильная композиция и viewport 1440 × 1000.

Не проверено без аккаунта/развёрнутого проекта:

- Реальный Supabase Auth, Storage, Realtime и сетевые вызовы Edge Function.
- Одновременное бронирование с двух устройств и интеграционный тест `tests/integration.mjs`.
- Turnstile с настоящими Site key / Secret key.
- Публикация GitHub Pages и проверка на физическом iPhone Safari.

В локальном SQL-тесте схемы Auth/Storage и роли имитируют необходимые интерфейсы Supabase; расширение pgcrypto и подключение таблицы к Realtime пропускаются. Сам SQL бронирований, ограничений и RLS выполняется в PostgreSQL-движке. Это не замена проверке в настоящем проекте. В README есть инструкции и чек-лист для завершения проверки.

Не добавлялись фиктивные товары, бронирования или локальная база. Публикация не выполнялась: аккаунты и настройки внешних сервисов не предоставлены.
